Running the live demo on a MacBook

  • All model work stays on the Windows PC with the RTX 4060. quantlab serve listens only on the PC itself (127.0.0.1:8000).
  • A Cloudflare quick tunnel (cloudflared 2026.10.7, checksum and code signature verified) opens an outbound connection from the PC and gives the service a temporary https://….trycloudflare.com address. No ports are opened on the PC's network.
  • The MacBook needs only a browser: it opens the address, enters the API key, and asks questions from any network. Every request still passes the checks on page 1.
  • The address changes whenever the tunnel restarts, and the demo is live only while the PC is on and awake.
