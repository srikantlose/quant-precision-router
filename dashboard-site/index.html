Which quantization does each task actually need?

One model, served at seven precisions, run through 2,067 prompts each on a single RTX 4060. Every number below is measured, not estimated.

01

How it works, in four moves

Measure everything, decide what "good enough" means per task, learn to predict it from the prompt, then route. Full flowchart in the study guide.

STEP 1 · MEASURE

Run every task on every rung

1,467 graded tasks + 600 safety prompts × 7 precisions = 14,469 scored runs. Plus KL-divergence against F16 on WikiText-2.

STEP 2 · LABEL

Find each task's minimum rung

"Required precision" = the cheapest rung that solves the task confidently, with at most one failure among the rungs above it.

STEP 3 · PREDICT

Guess it from the prompt alone

Sentence embeddings + 13 surface features → a classifier, cross-fitted so no task ever predicts its own label.

STEP 4 · ROUTE

Serve the cheapest safe rung

A rung is allowed only if accuracy, answer-stability and safety all clear a bar. Cheapest allowed rung wins; F16 is always allowed.

10

Honest limits

What these results can't tell you yet.

  • At the default bars the router still serves F16 everywhere. The pooled accuracy model is a straight line in log-bits, but the real curve is a knee (Q2_K collapses, Q4 and up are flat), so it over-predicts F16 and the 2-point accuracy slack fails almost everywhere. The winner matrix (direct from data) shows what the router is missing.
  • The required-precision predictor only just beats always guessing the most common class. Prompt text alone is a weak signal here.
  • About half the 84 policy cells have under 5 training tasks; they fall back to a category-only model instead of extrapolating.
  • The refusal grader is a phrase list and undercounts real refusals. An LLM-judged audit to measure that error is still to run.
  • Single model, single GPU. F16 was expected to spill out of VRAM on 8 GB; it didn't, so the "memory cliff" never showed up.
  • Generated logic / complex tasks fell short (10 of 38): the teacher kept writing puzzles with more than one valid answer.
  • Still to build: the live routing API, the adversarial attack evaluation, and the final written report.
