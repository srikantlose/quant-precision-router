The problem

One precision for everything is wasteful

Serving every prompt at full 16-bit precision burns memory on easy prompts; squeezing everything to 2-bit wrecks hard ones. Does the right precision depend on the task?

What we did

Measure, label, predict, decide

Ran 2,067 prompts on 7 quantized versions of one model, found each task's cheapest working version, tried to predict that from the prompt, and built a rule that picks the cheapest safe version.
